# Lynca

One-page bilingual website for Lynca, an independent web agency.

## Run locally

Open `index.html` directly or serve the directory with any static web server.

## Contact form

The contact form uses FormSubmit to deliver messages to `gigicirillo@gmail.com`. On the first submission, FormSubmit may ask the recipient to activate the endpoint by email.

## Deployment

The project is fully static and can be deployed on GitHub Pages, Cloudflare Pages, Netlify, Vercel or any standard web host.
